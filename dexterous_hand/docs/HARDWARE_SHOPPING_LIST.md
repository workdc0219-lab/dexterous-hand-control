## 十一、注意事项

### 11.1 购买前确认

- [ ] 确认开发板的CAN接口引脚位置
- [ ] 确认电机的电压和电流参数
- [ ] 确认编码器的接口类型（I2C/脉冲）
- [ ] 确认摄像头的分辨率和帧率
- [ ] 确认电源的输出电压和电流

### 11.2 购买后检查

- [ ] 检查所有元件是否完好
- [ ] 测试开发板的基本功能
- [ ] 测试电机的转动方向
- [ ] 测试编码器的读数
- [ ] 测试摄像头的成像质量

### 11.3 常见问题

**Q: 电机不转怎么办？**
- 检查电源电压是否足够
- 检查电机驱动的使能引脚
- 检查PWM信号是否正常

**Q: 编码器读数不准怎么办？**
- 检查磁铁与编码器的距离
- 检查电源电压是否稳定
- 检查信号线是否接触良好

**Q: CAN通信失败怎么办？**
- 检查CAN总线终端电阻
- 检查CAN_H/CAN_L是否接反
- 检查波特率是否一致
