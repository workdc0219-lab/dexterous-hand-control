## 一、项目概述

### 1.1 基本信息
- **项目名称**：灵巧手视觉驱动系统
- **项目类型**：毕业设计（毕设）
- **项目目标**：通过摄像头识别手部姿态，控制机械灵巧手实时模仿人手动作
- **技术亮点**：基于分布式CAN总线架构的灵巧手控制

### 1.2 技术路线
```
USB摄像头 → YOLOv8手部关键点检测(21点) → 角度映射(5指×3关节)
    ↓
UART发送(115200bps) → 主控板(STM32F407) → CAN广播(1Mbps)
    ↓
手指节点(STM32F103 ×5) → TB6612驱动 → N20电机 → 手指动作
    ↑
内置霍尔编码器(位置反馈) + FSR402(触觉反馈)
```

## 六、通信协议

### 6.1 UART协议（PC→主控板）

```
波特率：115200 bps
数据格式：8N1

帧格式（13字节）：
┌──────┬─────────┬─────────┬─────┬─────────┬──────┬──────┐
│ 0xAA │ angle0  │ angle1  │ ... │ angle4  │ CRC8 │ 0x55 │
│ 帧头 │ 2字节   │ 2字节   │     │ 2字节   │ 校验 │ 帧尾 │
└──────┴─────────┴─────────┴─────┴─────────┴──────┴──────┘

角度范围：0-180度，小端序
```

### 6.2 CAN协议（主控板→手指节点）

```
波特率：1 Mbps
帧格式：标准帧（11位ID）

CAN ID分配：
- 0x001：手指1（大拇指）
- 0x002：手指2（食指）
- 0x003：手指3（中指）
- 0x004：手指4（无名指）
- 0x005：手指5（小指）

数据帧（8字节）：
┌─────────┬─────────┬─────────┬──────┬──────┐
│ 关节1   │ 关节2   │ 关节3   │ CRC  │ 保留 │
│ 2字节   │ 2字节   │ 2字节   │ 1字节│ 1字节│
└─────────┴─────────┴─────────┴──────┴──────┘

角度范围：0-180度，小端序

负载率估算：
- 100Hz控制周期
- 每帧约100bit（含开销）
- 负载率 = 5×100×100 / 1000000 = 5%（远低于30%安全阈值）
```

### 6.3 编码器接口（内置霍尔）

```
接口类型：正交编码器（A/B相）
分辨率：6脉冲/转（电机端）
4倍频后：24脉冲/转（电机端）
经100:1减速比后：2400脉冲/圈（关节端）
物理分辨率：360°/2400 = 0.15°

接线：
- 电机编码器A相 → STM32 TIMx_CH1
- 电机编码器B相 → STM32 TIMx_CH2
- 配置为硬件编码器模式，自动计数
```

## 七、控制算法

### 7.1 PID参数（初始值）

```c
// PID参数（初始值，需现场微调）
#define PID_KP  5.0f    // 从5开始试
#define PID_KI  0.0f    // 位置控制通常不需要
#define PID_KD  0.5f    // 抑制超调

// 控制周期
#define CONTROL_PERIOD_MS  10  // 100Hz
```

### 7.2 PID整定步骤

```
1. 设KI=0, KD=0.5, KP从1.0开始
2. 逐渐增大KP，直到手指开始振荡
3. 将振荡时的KP乘以0.6作为最终值
4. 保持KP不变，逐渐增大KD消除超调
5. 位置控制通常不需要KI（容易积分饱和）
```

### 7.3 死区补偿

```c
// N20电机死区补偿（PWM低于15-20%时不转）
#define DEAD_ZONE  300   // 约15% PWM（假设满幅2000）

int16_t deadzone_compensate(int16_t pid_output) {
    if (pid_output > 0 && pid_output < DEAD_ZONE) {
        return DEAD_ZONE;
    } else if (pid_output < 0 && pid_output > -DEAD_ZONE) {
        return -DEAD_ZONE;
    }
    return pid_output;
}
```

### 7.4 安全保护

```c
// 堵转检测
#define STALL_TIMEOUT_MS  500    // 500ms无位置变化判定堵转
#define STALL_CURRENT_MA  500    // 电流超500mA判定堵转

// 紧急停止
// 1. 硬件：急停按钮切断电机电源
// 2. 软件：UART/CAN预留急停指令

// 通信超时
#define COMM_TIMEOUT_MS  1000    // 1秒无通信进入安全模式
```

## 九、常见问题

### 9.1 电机不转
- 检查电源电压是否足够
- 检查TB6612的使能引脚(STBY)
- 检查PWM信号是否正常
- 检查是否在死区范围内

### 9.2 编码器读数不准
- 检查A/B相接线是否正确
- 检查定时器是否配置为编码器模式
- 检查是否有干扰（加滤波电容）

### 9.3 CAN通信失败
- 检查CAN_H/CAN_L是否接反
- 检查终端电阻是否正确（仅两端各120Ω）
- 检查波特率是否一致（1Mbps）
- 检查节点ID是否冲突

### 9.4 电源不稳定
- 检查电源功率是否足够（5V 10A）
- 检查滤波电容是否靠近驱动芯片
- 检查是否加了自恢复保险丝

### 9.5 FSR读数异常
- 检查分压电阻是否为10kΩ
- 检查ADC引脚是否正确（PA2）
- 检查是否与电机PWM引脚冲突

## 十二、关键决策总结

| 决策点 | 最终方案 | 理由 |
|--------|----------|------|
| 电机电压 | 6V | 兼容5V供电 |
| 电机转速 | 100RPM | 兼顾速度和扭矩 |
| 传动比 | 1:1直接驱动 | N20已有100:1内置减速 |
| 编码器 | N20内置霍尔 | 避免I2C地址冲突，精度足够 |
| FSR分压 | 10kΩ | 匹配ADC范围 |
| TB6612数量 | 10个 | 每节点需要2个 |
| 电源 | 5V 10A | 避免堵转欠压 |
| 打印材料 | PETG/ABS | 避免PLA蠕变 |
| PID初始值 | KP=5, KI=0, KD=0.5 | 保守起步，现场微调 |
| 死区补偿 | 15-20% PWM | 解决N20低电压不转问题 |
| CAN终端电阻 | 仅两端各120Ω | 避免总线锁死 |
| 架构 | 分布式5节点 | 工业标准方案，减少线束 |
