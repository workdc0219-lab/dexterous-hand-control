## 一、项目概述

### 1.1 项目名称
**灵巧手视觉驱动系统** - 基于视觉识别的灵巧手抓取控制系统

### 1.2 项目类型
毕业设计项目（毕设）

### 1.3 项目目标
通过摄像头识别手部姿态，控制机械灵巧手实时模仿人手动作，实现抓取操作。

### 1.4 技术路线
```
摄像头采集 → YOLOv8手部关键点检测 → 关节角度映射 → UART发送 → 主控板 → CAN总线 → 手指节点 → 电机控制
```

## 二、系统架构

### 2.1 硬件架构

```
┌─────────────────────────────────────────────────────────────┐
│                      PC端 (视觉处理)                         │
├─────────────────────────────────────────────────────────────┤
│  摄像头 (USB 640×480@30fps)                                  │
│      ↓                                                       │
│  YOLOv8-pose (手部21关键点检测)                               │
│      ↓                                                       │
│  关键点→角度映射 (5个手指角度)                                 │
│      ↓                                                       │
│  UART串口发送 (115200bps)                                    │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│                   主控板 (STM32F407VGT6)                      │
├─────────────────────────────────────────────────────────────┤
│  UART接收 (DMA + 空闲中断)                                   │
│      ↓                                                       │
│  CAN总线广播 (1Mbps)                                        │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│              手指节点 (STM32F103C8T6 × 5)                     │
├─────────────────────────────────────────────────────────────┤
│  每个节点控制1根手指的3个关节                                   │
│  - 关节1 (掌指关节 MCP)                                       │
│  - 关节2 (近指关节 PIP)                                       │
│  - 关节3 (远指关节 DIP)                                       │
│                                                              │
│  每个关节包含:                                                │
│  - N20微型减速电机 (带编码器)                                  │
│  - TB6612FNG电机驱动                                         │
│  - AS5600磁编码器 (位置反馈)                                  │
│                                                              │
│  每个指尖包含:                                                │
│  - FSR402薄膜压力传感器 (触觉反馈)                             │
└─────────────────────────────────────────────────────────────┘
```

### 5.2 CAN协议设计

```c
// CAN ID定义
#define CAN_ID_FINGER1  0x001  // 手指1 (大拇指)
#define CAN_ID_FINGER2  0x002  // 手指2 (食指)
#define CAN_ID_FINGER3  0x003  // 手指3 (中指)
#define CAN_ID_FINGER4  0x004  // 手指4 (无名指)
#define CAN_ID_FINGER5  0x005  // 手指5 (小指)

// 数据帧格式
// Byte 0-1: 关节1角度 (0-180度)
// Byte 2-3: 关节2角度 (0-180度)
// Byte 4-5: 关节3角度 (0-180度)
// Byte 6: CRC校验
// Byte 7: 保留
```
